# RDViewer — Markdown Reader

VS Code의 Markdown 미리보기에서 출발한 로컬 문서 리더입니다.
파일 탐색기와 문서 탭으로 문서를 오가고, 본문 폭·글자 크기·테마를 읽기 편하게 조절합니다.
탐색기는 Markdown(.md, .markdown, .mdown), PNG 이미지, MP4 영상, HTML(.html, .htm)과 해당 파일이 있는 폴더를 표시합니다.
탐색기 위의 파일 형식 버튼을 눌러 MD·PNG·MP4·HTML을 여러 개 선택하거나 MD만 표시할 수 있습니다. 선택은 이 기기에 저장되며 탐색기와 검색에 적용됩니다.
**Aa → 문서 목차 표시**에서 오른쪽 목차를 켜고 끌 수 있습니다. 기본은 켜짐이며 선택은 저장됩니다.
썸네일은 만들지 않으며, 파일을 클릭할 때만 이미지 또는 영상 플레이어를 엽니다.
검색할 때도 폴더 구조를 유지하며, 일치하는 문서가 있는 경로를 자동으로 펼칩니다.
탐색기 위쪽의 **모든 폴더 펼치기 / 모든 폴더 접기** 버튼으로 표시된 폴더 전체를 제어합니다.
접은 상태는 목록 새로고침에도 유지되고, 문서·폴더·검색어를 바꾸면 해당 경로가 다시 펼쳐집니다.

## 시작

Node.js 22.13 이상이 필요합니다. 저장소 루트에서:

```sh
npm --prefix tools/md-viewer install
node tools/md-viewer/server.mjs --root .
```

[RDViewer 열기](http://127.0.0.1:4317)

macOS에서는 이 폴더의 `RDViewer.command`를 더블클릭해 저장소 문서를 열 수도 있습니다.
처음 실행할 때만 필요한 npm 패키지를 설치합니다. 실행 중인 RDViewer를 재사용하며,
서버가 없으면 백그라운드에서 시작합니다.

## 검색

상단 검색창은 **추가한 모든 폴더와 파일의 이름·경로 및 문서 내용**을 함께 찾습니다.
결과에는 일치하는 내용과 행 번호가 표시되며, 결과를 누르면 해당 문구를 문서에서 강조합니다.
열린 문서만 찾으려면 도구 모음의 돋보기 또는 **⌘/Ctrl+F**를 사용하세요.
**Enter**는 다음 결과, **Shift+Enter**는 이전 결과, **Esc**는 찾기 닫기입니다. 읽기·원문 모두 지원합니다.

내용 검색은 요청당 200개 결과·32MB 읽기·약 2.5초 범위로 제한하며, 범위를 넘기면 검색 상태에 일부 결과임을 표시합니다.
검색어를 구체적으로 입력하면 검색 범위를 좁힐 수 있습니다.

## 이미지와 영상

폴더 트리에서 PNG·MP4 파일을 클릭하면 같은 화면과 탭에서 열립니다. 목록에 썸네일을 생성하거나 영상을 미리 읽지 않습니다.
영상은 재생에 필요한 범위부터 읽으며, 다른 파일을 선택하면 기존 재생을 멈추고 미디어 리소스를 해제합니다.
브라우저와 운영체제가 지원하는 MP4 코덱만 재생할 수 있습니다. H.264 영상·AAC 오디오 형식을 권장합니다.
본문 찾기·원문 보기·목차는 Markdown 파일에서 사용합니다. PNG·MP4는 이름·경로로 검색하고 바이너리 내용은 검색하지 않습니다.

## 폴더별로 보기

사이드바의 **하나의 탐색 트리**에서 **MyProject, Notes** 등 추가한 폴더를 펼칩니다.
각 폴더 아래에 하위 폴더와 Markdown·PNG·MP4 파일이 바로 표시되고, 여러 폴더를 동시에 펼쳐둘 수 있습니다.
폴더를 펼칠 때는 현재 문서를 바꾸지 않으며 파일을 누르면 해당 문서를 엽니다.
상단 로고 옆 **⋯ 폴더 메뉴**에서 **폴더 추가 / 파일 추가**, 폴더 관리와 전체 폴더 보기를 사용할 수 있습니다.
앱을 시작하면 마지막 문서와 사이드바 목록을 바로 표시합니다.
예를 들어 `MyProject-feature`, `MyProject-design`이 같은 저장소의 worktree라면
상위에는 `MyProject` 하나로 묶입니다.

이 분류는 **로컬 Git 저장소 정보**를 사용합니다. GitHub 로그인이나 네트워크 연결은 필요하지 않습니다.
Git이 없는 폴더는 독립 폴더로 표시하고, 이름만 비슷한 별개 저장소는 합치지 않습니다.
같은 원격 주소에서 따로 clone한 저장소는 로컬 저장소가 다르므로 별도 그룹으로 표시합니다.

1. **폴더 추가**를 눌러 폴더를 선택합니다. 브라우저에서는 폴더의 절대 경로를 입력합니다.
   Mac 앱에서는 **파일 → 폴더 추가…** (`⌘⇧O`)로 여러 폴더를 함께 선택할 수도 있습니다.
2. 추가한 폴더를 펼치고 파일을 누릅니다. 다른 폴더의 펼침 상태도 유지됩니다.
3. 파일만 추가하면 같은 탐색 트리에 파일 항목으로 표시됩니다.
4. 폴더 등록을 해제해도 실제 폴더와 문서는 삭제되지 않습니다. 기본 폴더는 유지됩니다.

등록한 폴더 안의 Markdown을 Finder나 Codex에서 열면 해당 폴더로 전환합니다.
같은 폴더는 중복 등록하지 않으며, 이름이 같은 폴더는 경로로 구분할 수 있습니다.
등록 목록은 Mac의 `~/Library/Application Support/RDViewer/projects.json`에 저장됩니다.
Windows에서는 `%APPDATA%\RDViewer\projects.json`에 저장됩니다.
목록에는 폴더 경로만 저장하며 문서 내용은 복사하지 않습니다. 이동·삭제한 폴더는 새 경로로 다시 등록하세요.

```sh
node tools/md-viewer/open.mjs --project "/Users/you/Work/MyProject"
```

## Codex · Claude 문서 열기

상단 메뉴의 **파일 추가** 또는 **⌘/Ctrl+O**를 사용합니다. 데스크톱 앱에서는 파일 선택창이 바로 열립니다.
경로를 붙여넣으려면 **⋯ → 경로로 파일 추가…**를 사용합니다.

- **로컬 파일 경로 또는 Markdown 링크**를 붙여넣으면 현재 폴더 밖 문서도 엽니다.
  `/Users/you/문서.md`, `[문서](</Users/you/문서.md:12>)`, `file:///Users/you/doc.md`를 지원합니다.
  `:12`, `#L12` 등 행 번호는 경로에서 제거하며 해당 줄로 이동하는 기능은 아닙니다.
- **Claude 웹 등에서 내려받은 .md 파일**은 파일 선택 또는 드래그 앤 드롭으로 엽니다.
  브라우저에서 선택한 파일은 탭 메모리에만 보관합니다. 새로고침 후에는 다시 선택해야 합니다.
- **상대 이미지·문서 링크도 필요하면 경로 붙여넣기**를 사용합니다.
  외부 문서는 선택한 파일의 부모 폴더 안에서만 상대 리소스를 읽습니다. 상위 폴더로 나가는 링크는 제한됩니다.
- `sandbox:`나 클라우드 URL은 이 Mac의 파일 경로가 아닙니다. 먼저 파일을 다운로드해 주세요.

Codex·Claude의 자체 파일 미리보기는 그대로입니다. 그 화면의 링크 클릭을 자동으로 가로채지는 않습니다.

AI 에이전트나 터미널에서 바로 연결할 수도 있습니다:

```sh
node tools/md-viewer/open.mjs "/Users/you/문서.md"
# 브라우저를 띄우지 않고 응답에 붙일 RDViewer URL만 받기
node tools/md-viewer/open.mjs --no-browser "/Users/you/문서.md"
```

서버가 없으면 자동으로 시작하고, 실행 중인 RDViewer 서버가 있으면 재사용합니다.
외부 문서의 URL은 해당 서버가 실행되는 동안 유효합니다.

## macOS 앱

```sh
npm --prefix tools/md-viewer run install:mac
```

`~/Applications/RDViewer.app`에 설치합니다. Finder의 `.md` 파일 **다음으로 열기 → RDViewer**,
RDViewer 앱 아이콘에 파일 드래그, 앱 메뉴 **파일 → 파일 추가…**를 사용할 수 있습니다.
기본 Markdown 앱 설정은 변경하지 않습니다.

앱은 Swift/AppKit + WKWebView 창이며 렌더러와 Node 의존성을 포함합니다.
빌드한 Mac의 Node 실행 경로를 사용하므로 다른 Mac에 배포하는 독립 설치 패키지는 아닙니다.
Node 경로를 삭제·변경했다면 다시 빌드하세요. Xcode 명령행 도구가 필요합니다.
앱을 종료해도 다른 RDViewer 브라우저 탭이 사용할 수 있도록 로컬 서버는 유지됩니다.
등록한 `rdviewer://open?path=<URL 인코딩된 절대 경로>`도 같은 파일 열기 연결을 사용합니다.

## Windows 앱

[최신 Release](https://github.com/on1659/RDViewer/releases/latest)에서
`RDViewer-*-windows-x64-setup.exe` 하나를 내려받아 실행하고 설치합니다.
설치 프로그램에 Electron과 필요한 파일이 모두 포함되어 있으며, Node.js를 별도로 설치할 필요가 없습니다.
설치 후 시작 메뉴에서 **RDViewer**를 실행합니다.

- **파일 → 파일 추가**: `Ctrl+O`, 여러 파일 선택 가능.
- **파일 → 폴더 추가**: `Ctrl+Shift+O`, 여러 폴더 선택 가능.
- `.md` 파일의 **연결 프로그램 → 다른 앱 선택**에서 `RDViewer.exe`를 지정할 수 있습니다.
  기본 앱 변경은 Windows의 선택 화면에서 직접 설정합니다.
- `C:\Work\폴더\문서.md`처럼 공백·한글이 있는 로컬 드라이브 경로를 지원합니다.
- Git worktree 묶음을 사용하려면 Windows에 Git이 설치되어 있어야 합니다.

Windows에서 소스로 빌드할 때:

```sh
npm --prefix tools/md-viewer ci
npm --prefix tools/md-viewer run build:win
```

Windows 앱은 Electron 런타임을 포함합니다. 문서 서버는 `127.0.0.1:4318`에서만 실행되며
앱 종료 시 함께 종료됩니다. 해당 포트를 다른 프로그램이 쓰면 시작 오류를 표시합니다.
배포물은 코드 서명되지 않았으며, Windows 검증 범위는 각 Release 설명을 확인하세요.

## 서버 직접 실행

다른 폴더를 읽으려면:

```sh
node tools/md-viewer/server.mjs --root "/Users/you/Documents" --port 4317
```

`--root`의 상대 경로는 실행한 현재 폴더 기준입니다. `npm --prefix tools/md-viewer start`는
패키지 폴더에서 실행되므로 저장소를 읽으려면 `-- --root ../..`을 붙입니다.
종료는 실행한 터미널에서 `Ctrl+C`입니다.

## 제공 기능

- `.md`, `.markdown`, `.mdown`, `.png`, `.mp4` 파일 탐색과 파일명 검색
- Markdown 내용 검색, PNG 보기, MP4 재생·일시 정지·탐색(지원 코덱에 한함)
- 최근 열어본 파일 최대 30개 저장·다시 열기·기록 지우기
- 여러 문서를 여는 탭, 자동 목차와 제목 이동
- 읽기 / 원문 전환, 집중 모드
- 라이트 / 페이퍼 / 세피아 / 다크 / VS Code Dark(차콜·블루) / Visual Studio(퍼플) / 미드나이트 / 시스템 테마
- 배경·본문·강조색 직접 지정(색상 선택기 또는 HEX), 대비 표시와 색상 초기화
- 글자 크기·본문 폭 조절, 테마 설정 저장
- 표, 인용, 코드 강조, 코드 복사, 폴더 안 상대 문서 링크와 이미지
- 문서별 스크롤 위치와 읽기 설정 유지
- 좁은 화면에서 접히는 탐색기와 목차

테마는 **Aa → 화면 테마**에서 선택합니다. 기존에 `Visual Studio Dark`로 표시했던
차콜·블루 테마는 `VS Code Dark`로 이름을 바로잡았으며, 기존 선택은 같은 색상으로 유지합니다.
보라색 테마는 별도의 `Visual Studio · 퍼플` 항목입니다.

앱 아이콘은 `macos/RDViewer.icns`, 웹 아이콘은 `public/icon.svg`에 포함되어 있습니다.

## 로컬 동작과 제한

문서 내용은 외부 서버로 전송하지 않습니다. 서버는 `127.0.0.1`에만 바인딩합니다.
설치 이후 렌더러와 코드 강조 라이브러리도 로컬에서 로드합니다.
외부 이미지는 자동으로 요청하지 않으며, 외부 링크는 사용자가 눌렀을 때 새 탭으로 열립니다.
문서의 HTML은 실행하지 않고 문자로 표시합니다.

지정한 폴더와 명시적으로 연 외부 파일의 부모 폴더에서 문서·이미지 읽기만 제공합니다.
외부 폴더 전체를 탐색 목록에 추가하지는 않습니다.
`.claude`, `.codex` 같은 숨김 폴더의 Markdown과 `.workflow.md` 같은 숨김 문서도 탐색하고 열 수 있습니다.
버전 관리 내부 폴더(`.git`, `.hg`, `.svn`)는 차단하고,
탐색기에서 심볼릭 링크, `node_modules`, `old`, `build`, `dist`, `coverage`, `Pods`, `vendor`를 제외합니다.
문서 5MB, 이미지 20MB, 목록 5,000개·깊이 20단계·디렉터리 20,000개로 제한합니다.
목록은 최대 3초 캐시됩니다. 외부에서 변경한 문서는 다시 열거나 페이지를 새로고침하면 반영됩니다.

브라우저와 macOS 앱에서 사용하는 로컬 리더입니다. 편집·저장,
실시간 파일 감시, Mermaid·수식 전용 렌더링, VS Code 확장 호환은 포함하지 않습니다.

## 확인

```sh
npm --prefix tools/md-viewer test
```

서버 테스트는 폴더 탈출·심볼릭 링크·숨김 문서 열기·버전 관리 내부 경로 차단·대용량 문서·외부 Origin 접근 등을 확인합니다.
설계 근거는 [VS Code 분석](VSCODE-ANALYSIS.md)에 정리했습니다.

## HTML 및 AI 도구

HTML·HTM 파일을 클릭하면 별도 미리보기에서 CSS·JavaScript를 실행합니다. 미리보기 창은 하나만 유지하고 닫으면 해제합니다. Claude·Codex·GPT 로컬 에이전트가 CLI·MCP·인증된 HTTP API로 열기·상태 확인·클릭·입력·스크롤·영상 재생·스크린샷·무음 녹화를 실행할 수 있습니다. 녹화 기본10fps, 최대15fps·120초·너비1920px이며 결과는 사용자 전용 artifacts 폴더에 기록합니다.

설치 경로·명령 예·JSON 도구 스키마·MCP 연결: [API.md](API.md). 에이전트 지침 예: [AGENT-TOOLS.md](AGENT-TOOLS.md). 모델 API 키나 클라우드 SDK는 필요하지 않습니다. 브라우저의 ChatGPT가 localhost를 직접 호출하는 방식은 아니며 로컬 도구 실행부가 필요합니다.
