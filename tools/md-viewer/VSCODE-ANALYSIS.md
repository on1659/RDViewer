# Markdown 리더 설계 근거

RDViewer는 VS Code의 Markdown 미리보기에서 익숙한 읽기 흐름을 참고해 독립적으로 구현했다.
VS Code의 배포 코드나 스타일을 복사하지 않는다.

- 문서 탐색기, 열린 문서 탭, 읽기 화면과 제목 목차를 분리한다.
- 읽기와 원문을 같은 탭에서 전환하고, 문서별 스크롤 위치를 기억한다.
- 긴 코드와 표는 본문 안에서 가로 스크롤한다.
- 본문 너비·글자 크기·색상을 사용자 설정으로 제공한다.
- Markdown만 노출하는 폴더 트리와 프로젝트별 탐색을 사용한다.
- 외부 콘텐츠는 신뢰하지 않는다. 원시 HTML 렌더링을 끄고 로컬 파일 접근 범위를 제한한다.
- VS Code Dark와 Visual Studio 퍼플은 별도 테마이며 원본 제품의 완전한 복제는 아니다.

RDViewer의 현재 기능과 사용법은 [README](README.md)를 기준으로 한다.
