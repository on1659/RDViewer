# RDViewer

로컬 Markdown 문서를 편하게 읽고 PNG·MP4·HTML을 여는 뷰어입니다.

- **폴더 추가** (`Ctrl+Shift+O`)에서 문서 폴더를 선택하세요. 여러 폴더를 함께 등록할 수 있습니다.
- **파일 추가** (`Ctrl+O`)로 MD·PNG·MP4·HTML 파일을 선택할 수 있습니다. RDViewer 로고를 눌러도 두 추가 메뉴가 열립니다.
- 폴더를 동시에 펼쳐 보고, 탐색기 위의 필터로 표시할 형식을 고르세요. 오른쪽 버튼으로 모든 폴더를 펼치거나 접을 수 있습니다.
- 톱니바퀴에서 글꼴·테마·단축키·업데이트를 설정합니다. 설치된 글꼴과 VS Code Dark·Visual Studio 퍼플 테마를 고를 수 있습니다.
- 지구본 또는 로고의 **주소 열기** (`Ctrl+Shift+L`)에서 `http://localhost:5014` 같은 로컬 웹주소를 입력해 HTML 웹페이지를 엽니다. 주소창·탭·최근 기록과 캡처·녹화를 사용할 수 있습니다. HTTPS는 신뢰된 인증서가 필요합니다.
- Mac에서는 위 단축키의 Ctrl 대신 ⌘를 사용합니다.

파일은 읽기 전용입니다. 목록에서 폴더를 제거해도 원본 파일은 삭제되지 않습니다.

## 업데이트

**설정 → 앱·업데이트**에서 확인합니다. 기본으로 [GitHub Releases](https://github.com/on1659/RDViewer/releases)의 새 안정 버전을 확인·다운로드하고, 준비되면 **재시작하여 업데이트**로 적용합니다. 자동 업데이트를 끄거나 직접 확인할 수도 있습니다. 문서 내용과 폴더 경로는 업데이트 서버로 전송하지 않습니다.

## Windows에서 Markdown 기본 앱으로 사용

`.md` 파일을 우클릭하고 **연결 프로그램 → 다른 앱 선택 → PC에서 앱 선택**으로 이 폴더의 `RDViewer.exe`를 선택하세요. Windows에서 표시하는 기본 앱 선택 항목을 이용하면 이후 더블클릭으로 열 수 있습니다.

폴더 묶음은 로컬 Git 정보를 이용합니다. Git이 설치되어 있지 않으면 각 폴더를 독립적으로 표시합니다.
