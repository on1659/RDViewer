# RDViewer

로컬 Markdown 문서를 읽는 전용 뷰어입니다.

- **파일 → 프로젝트 폴더 추가** (`Ctrl+Shift+O`)에서 문서 폴더를 선택하세요. 여러 폴더를 함께 등록할 수 있습니다.
- **파일 → Markdown 열기** (`Ctrl+O`)로 문서를 바로 열 수 있습니다.
- 사이드바에서 프로젝트를 고르고, 탐색기 위의 버튼으로 폴더를 모두 펼치거나 접으세요.
- 설정에서 VS Code Dark, Visual Studio 퍼플 등 읽기 테마를 고를 수 있습니다.
- Codex·Claude가 알려준 로컬 문서 경로를 **문서 열기**에 붙여 넣어도 됩니다.

파일은 읽기 전용입니다. 프로젝트 목록에서 폴더를 제거해도 원본 파일은 삭제되지 않습니다.

## Windows에서 Markdown 기본 앱으로 사용

`.md` 파일을 우클릭하고 **연결 프로그램 → 다른 앱 선택 → PC에서 앱 선택**으로 이 폴더의 `RDViewer.exe`를 선택하세요. Windows에서 표시하는 기본 앱 선택 항목을 이용하면 이후 더블클릭으로 열 수 있습니다.

프로젝트 묶음은 로컬 Git 정보를 이용합니다. Git이 설치되어 있지 않으면 각 폴더가 별도 프로젝트로 표시됩니다.
